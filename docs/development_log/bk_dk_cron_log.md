#  cron による bk_dk() 定期実行の設定

## 導入経緯

`db_bk.sh` によりデータベースのバックアップを手動で取得できるようになったため、バックアップ取得漏れを防ぎ、一定間隔で復元可能な状態を維持することを目的として、`cron` による定期実行機能を導入した。

---

## 現時点での設計方針

- `cron` は `db_bk.sh` を定期実行し、データベースのバックアップファイルを自動作成する。
- データベースの更新有無にかかわらず、定期的にバックアップファイルを作成する。
- `cron` の設定ファイルは専用の `cron/` ディレクトリで管理する。
- `cron` の設定ファイルには決まった拡張子が存在しないため、用途を明確にする目的で `.cron` 拡張子を採用し、機能名を含めたファイル名（例：`db_bk.cron`）で管理する。

---

## 定期実行の最低条件・実行日時・間隔

- `cron` を利用するためには、Linux（WSL）が起動しており、`cron` サービスが動作していることを前提とする。
- `db_bk.sh` は毎日 **23時45分** に自動実行し、当日のデータベースバックアップを取得する。
- 更新がない場合でもバックアップを取得することで、定期的な復元ポイントを確保する。
