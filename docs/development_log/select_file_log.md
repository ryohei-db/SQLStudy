# select_file 開発記録

## 作成経緯

任意のファイルを指定し、実行できる機能として `select_file` の作成を開始する。

当初は `run_sql` としてSQLファイルを実行する機能を想定していたが、今後SQL以外のファイル形式にも対応できるよう、機能名を `select_file` に変更した。

## 現時点の設計方針

- 格納フォルダ名とファイル名をそれぞれ引数として受け取る
- 第1引数を格納フォルダ名、第2引数を拡張子を含むファイル名とする
- `BASE_DIR` を基準に格納フォルダ名とファイル名を組み合わせ、対象ファイルのパスを生成する
- 1回の処理で実行するファイルは1つのみとする
- 引数が指定されていない場合は入力待ちとし、格納フォルダ名とファイル名の入力を促す
- 現時点ではSQLファイルを実行対象とし、必要に応じてPythonやShellなど対応ファイル形式を追加する
- 今後必要に応じて、Pythonなど各ファイル形式に対応した実行処理を追加する
- 実行方法を入力値またはファイル拡張子から判定し、対応する実行処理へ分岐する
- 対応するファイル形式ごとに実行コマンドを切り替える（例：SQL、Python、Shell）
- 実行前に対象ファイルと実行方法を表示し、実行可否（y/n）の確認を行う
- 実行を中止した場合は処理を終了する
- 単独実行だけでなく、他スクリプトから `bash` コマンドで呼び出して利用できる構成とする

## 対象ファイルパスの生成

`select_file.sh` の格納場所を基準に1つ上のディレクトリへ移動し、`SQLStudy` を `BASE_DIR` とする。

第1引数で受け取った格納フォルダパスと、第2引数で受け取ったファイル名を `BASE_DIR` に組み合わせ、対象ファイルの絶対パスを生成する。

例：

`select_file sql/EXISTS test.sql`

第1引数：sql/EXISTS
第2引数：test.sql

生成される対象ファイルパス：

`${BASE_DIR}/sql/EXISTS/test.sql`

これにより、SQLファイルだけでなく、今後Pythonファイルなどを追加した場合も同じパス生成処理を利用できる。



## 単一ファイル実行とする理由

複数ファイルを引数として受け取る場合、引数の個数判定や複数ファイルの実行制御が必要になる。

また、今後任意のファイル形式に対応する場合は、ファイルごとに実行方法が異なる可能性がある。

そのため、対象ファイルを1つずつ指定して実行する単純な構成とし、`select_file` は1回につき1ファイルのみを処理する。

## ディレクトリ構成とパス指定方針

共通的に使用するスクリプトは `pubfun`、SQL・DB操作に関するスクリプトは `sqlfun` へ集約し、`BASE_DIR` を基準としてパスを生成する構成に統一している。

一方、SQLファイルは学習単元ごとの分類を維持する必要があり、共通フォルダへ集約すると対象SQLの学習内容が判別しにくくなる。

そのため、SQLファイルは `sql` 配下の各単元フォルダ内に配置したままとし、`select_file` では `BASE_DIR` から見た格納フォルダパスを指定する方式とする。


## 今後の検討

ファイル形式ごとに実行方法が異なるため、対応形式を追加する際は拡張子などからファイル形式を判定し、それぞれに対応した実行処理を追加する。

また、現在はSQLファイルのみ対応しているが、必要に応じてPythonなどのファイル形式にも対応し、実行方法を拡張する。

実行方法の追加に伴い、実行前確認やエラー処理についても各ファイル形式に応じた処理を検討する。

## 指定方法

`select_file` は、第1引数に `BASE_DIR` から見た格納フォルダパス、第2引数に拡張子を含むファイル名を指定する。

例：

```bash
select_file sql/EXISTS test.sql
```


## 他スクリプトからの利用方針

`select_file.sh` は単独で実行できるスクリプトとして実装し、必要に応じて他のスクリプトから `bash` コマンドで呼び出して利用する。

呼び出し元では `select_file.sh` の終了ステータス（`exit 0` / `exit 1`）を受け取り、後続処理の継続可否を判定する。

例：

```bash
bash "${BASE_DIR}/pubfun/select_file.sh" "sql/EXISTS" "test.sql"

if [ $? -ne 0 ]; then
    echo "select_file.sh の実行に失敗しました"
    return 1
fi
```

この構成により、ファイルパスの生成、存在確認、実行方法の選択、実行前確認などの共通処理を `select_file.sh` に集約し、他スクリプトから再利用できる構成とする。
