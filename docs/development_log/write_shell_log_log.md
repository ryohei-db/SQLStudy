# write_shell_log.sh 開発記録

## 目的

シェルスクリプトの実行方法を統一し、実行履歴を共通ログとして記録するため、`write_shell_log.sh` を実装した。

---

## 実装内容

### シェルスクリプト実行の共通化

各関数から対象スクリプトを直接実行せず、`write_shell_log.sh` を経由して実行する構成へ変更した。

```
関数
    ↓
write_shell_log.sh
    ↓
対象シェルスクリプト
```

これにより、シェルスクリプトの実行方法を統一した。

---


### 引数の受け渡し

第1引数を実行対象スクリプトとして取得し、`shift` により引数一覧から除外した。

その後、残りの引数を `"$@"` で対象スクリプトへそのまま渡す構成とした。

```bash
shell_target="$1"

shift

bash "${shell_target}" "$@"
```

---

### ログ出力

実行開始日時を取得し、対象スクリプトの実行結果を

- SUCCESS
- FAILED

としてログファイルへ追記するよう実装した。

ログは `printf` と `>>` を用いて追記形式で保存する。

---

### 終了ステータス

対象スクリプトの終了結果に応じて

- 正常終了：`exit 0`
- 異常終了：`exit 1`

を返し、呼び出し元から実行結果を判定できるようにした。

---

## 設計方針

シェルスクリプトの実行は、原則として `write_shell_log.sh` を経由する。

ただし `gsave.sh` は、ログ追記によって新たなGit差分が発生するため、シェルログの対象外とした。
