## update_readme 開発記録

## 新たな試み

README のディレクトリ構成を手動更新する運用から、自動更新する仕組みへ変更する。

処理を `update_readme.sh` として独立したスクリプトに分離し、`gsave.sh` から呼び出せる構成とすることで、処理の再利用性と保守性を向上させる。

## 作成経緯

プロジェクトのディレクトリ構成を変更するたびに README を手動で修正していたため、更新漏れや内容の不一致が発生する可能性があった。

そこで `tree` コマンドを利用し、現在のディレクトリ構成を自動取得して README へ反映する仕組みを作成することとした。

---

## 現時点の設計方針

- README 更新処理を `update_readme.sh` として独立したスクリプトで実装する
- `tree` コマンドで最新のディレクトリ構成を取得する
- `README.md` を読み込み、`<!-- TREE_START -->` ～ `<!-- TREE_END -->` の範囲のみを更新する
- README のその他の内容は保持する
- `TREE_START`・`TREE_END` が存在しない場合はエラー終了する
- 単体実行だけでなく、`gsave.sh` から `bash` コマンドで呼び出せる構成とする
- README 更新後に `gsave.sh` が Git の `add`・`commit`・`push` を実行する

---

## 最終まとめ

`tree` コマンドを利用して、README のディレクトリ構成を自動更新する `update_readme.sh` を作成した。

README 全体を書き換えるのではなく、`<!-- TREE_START -->` ～ `<!-- TREE_END -->` の範囲のみを更新することで、その他の内容を保持したまま最新のディレクトリ構成を反映できるようにした。

また、`TREE_START`・`TREE_END` の存在確認を実装し、マーカーが存在しない場合はエラーメッセージを表示して `exit 1` で終了するようにした。

正常系・異常系の単体テストを実施し、README の更新処理およびエラー処理が想定どおり動作することを確認した。
