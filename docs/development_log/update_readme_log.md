# update_readme 開発記録

## 新たな試み

README のディレクトリ構成を手動更新する運用から、自動更新する仕組みへ変更する。

処理を `update_readme.sh` として独立したスクリプトに分離し、`gsave.sh` から呼び出せる構成とすることで、処理の再利用性と保守性を向上させる。

## 作成経緯

プロジェクトのディレクトリ構成を変更するたびに README を手動で修正していたため、更新漏れや内容の不一致が発生する可能性があった。

そこで `tree` コマンドを利用し、現在のディレクトリ構成を自動取得して README へ反映する仕組みを作成することとした。

---

## 現時点の設計方針

- README 更新処理を `update_readme.sh` として独立したスクリプトで実装する
- `tree` コマンドで最新のディレクトリ構成を取得する
- `tree` の実行結果を一時ファイルへ保存する
- README のディレクトリ構成部分を一時ファイルの内容で更新する
- README の指定した範囲のみを書き換え、その他の内容は保持する
- 単体実行だけでなく、`gsave.sh` から `bash` コマンドで呼び出せる構成とする
- README 更新後に `gsave.sh` が Git の add・commit・push を実行する構成とする
