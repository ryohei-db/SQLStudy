# GitHubを導入した経緯とメリット
=====================================================================================

## 概要

SQLStudyを単なる学習環境ではなく、開発・検証環境として継続的に管理するためにGitHubを導入した。

======================================================================================

## 導入した理由

- いつ・なぜ・どこを・どういった考えで変更したのか記録するため
- クラウド上にバックアップをとることでデータの冗長性を確保しておきたかった
- 履歴の確認や各セーブポイントに戻れるようにしたかった
- 日々の学習・開発の過程と成果を成果物として残すため

======================================================================================

## 導入による改善

- 変更履歴・修正内容を確認できる
- 必要に応じて過去の状態へ戻せる
- GitHub上でコードと資料を一元管理できる
- クラウド上でのバックアップの確保
