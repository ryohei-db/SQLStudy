# log_sql.sh

## 概要

SQL実行処理を共通化するためのスクリプト。

各スクリプトから直接 `sqlite3` を実行せず、
`log_sql.sh` を経由してSQLを実行する。

---

# 処理の流れ

```text
呼び出し元スクリプト
        │
        ▼
log_sql.sh
        │
        ├─ 共通設定(settings.conf)の読み込み
        ├─ SQL実行開始時刻を取得
        ├─ sqlite3 を実行
        ├─ 終了ステータス取得
        ├─ 実行時間計測
        ├─ SQL実行ログを記録
        └─ 終了ステータスを呼び出し元へ返す
```

---

# 入力

## SQLファイル

```bash
bash log_sql.sh sample.sql
```

## SQL文字列

```bash
printf '%s\n' "${SQL}" |
bash log_sql.sh "CREATE:sample"
```

---

# 出力

- SQL実行結果
- 終了ステータス
- SQL実行ログ

---

# 主な役割

- 共通設定の読み込み
- sqlite3 の実行
- 実行開始時刻の取得
- 実行終了時刻の取得
- 実行時間の計算
- SQL実行ログの出力
- 呼び出し元へ終了ステータスを返却

---

# メリット

- SQL実行方法を統一できる
- ログ取得処理を共通化できる
- SQL実行仕様を1か所で管理できる
- 保守性・再利用性を向上できる
- 各スクリプトは本来の処理だけに集中できる
