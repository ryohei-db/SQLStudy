## db_bk() の機能

### 概要

- SQLiteデータベースのバックアップを取得する機能
- バックアップファイルを日時付きファイル名で保存する
- 古いバックアップファイルを自動削除し、世代管理を行う
- `.bashrc` の `db_bk` 関数を入口として、`bk_db.sh` を呼び出して実行する
- cron に登録することで定期的な自動バックアップにも対応する

### 主な機能

- SQLiteデータベースのバックアップを取得
- バックアップファイル名を日時から自動生成
- 古いバックアップファイルを自動削除し、世代管理を行う
- バックアップの成功・失敗を終了ステータスで判定
- エラー発生時に内容を表示する
- cron による定期実行に対応

### 作成経緯

- データベース更新時にバックアップを容易に取得できるようにするため作成した
- 手動バックアップだけでなく、定期的な自動バックアップにも対応できる構成とした
- バックアップファイルの増加を防ぐため、世代管理機能を追加した
- 他スクリプトから共通利用できるよう、単独実行可能なスクリプトとして設計した

### 設計

- `db_bk` 関数はCLIから実行するための入口とする
- 実処理は `bk_db.sh` に分離する
- `BASE_DIR` を基準としてデータベースファイルおよびバックアップ保存先を取得する
- バックアップファイル名は日時を付与して一意に生成する
- `cp` を利用してバックアップを作成する
- 保存期間・保存件数を超えたバックアップファイルは自動削除する
- 他スクリプトからは `bash bk_db.sh` として呼び出せる構成とする
- cron に登録することで定期的な自動バックアップを実現する
- 実行結果は終了ステータスで判定し、正常終了は `exit 0`、異常終了は `exit 1` とする
