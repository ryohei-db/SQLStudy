## gsave機能

### 概要

- Gitへの保存処理を自動化する機能
- 変更・新規作成されたファイルを確認し、GitHubへアップロードする
- `.bashrc` の `gsave` 関数を入口として、`gsave.sh` を呼び出して実行する

### 主な機能

- Gitリポジトリへ自動で移動
- 変更・新規作成の有無を確認
- 変更がない場合は処理を終了
- 変更されたディレクトリ名を取得
- 日付・時刻を取得
- コミットタイトルを自動生成
- `git add` を実行
- `git commit` を実行
- `git push` を実行
- GitHubへのアップロード後の状態を確認

### 作成経緯

- SQL学習やスクリプト開発により、GitHubへ保存する機会が増えた
- 毎回 `git add`、`git commit`、`git push` を手動で実行する手間があった
- コミットタイトルを毎回考える必要があった
- 保存作業の手間や操作ミスを減らすため、自動化することにした

### 設計

- `gsave` 関数はCLIから実行するための入口とする
- Git保存の処理本体は `gsave.sh` に分離する
- コミットタイトルは変更されたディレクトリ名・日付・時刻から自動生成する
- 変更がない場合は不要な `commit`、`push` を実行しない

### 効果

- Git保存作業の簡略化
- コミットタイトル作成の自動化
- 操作ミスの削減
- GitHubへの保存を継続しやすい環境を構築
