## select_file() の機能

### 概要

- 指定したファイルを実行する機能
- 対象ファイルの存在を確認し、存在する場合のみ実行処理へ進む
- 実行方法を選択し、対応する実行コマンドを実行する
- 実行前に確認入力を受け付け、`y` が入力された場合のみ実行する
- `.bashrc` の `select_file` 関数を入口として、`select_file.sh` を呼び出して実行する


### 主な機能

- 格納フォルダパスとファイル名を引数または対話入力で取得
- `BASE_DIR` を基準に対象ファイルの絶対パスを生成
- `test -f` を利用して対象ファイルの存在を確認
- 対応する実行方法を選択
- 実行前に `y / n` の確認入力を受け付ける
- `y` の場合のみ対象ファイルを実行
- `n` の場合は実行せず正常終了
- `y / n` 以外の入力はエラー終了
- 終了ステータスを利用して実行の成功・失敗を判定
- 実行結果をメッセージとして表示

### 作成経緯

- 任意のSQLファイルを指定して実行できる機能が必要になった
- 当初は `run_sql` として設計していたが、将来的な拡張性を考慮し `select_file` へ名称を変更した
- SQLだけでなくPythonなど他形式への対応も見据え、実行方法を選択できる構成とした
- 対象ファイルの誤実行を防ぐため、実行前の確認処理を追加した
- 他スクリプトから共通利用できるよう、単独実行可能なスクリプトとして設計した

### 設計

- `select_file` 関数はCLIから実行するための入口とする
- 実処理は `select_file.sh` に分離する
- 第1引数に `BASE_DIR` から見た格納フォルダパス、第2引数にファイル名を指定する
- `BASE_DIR` を基準として対象ファイルの絶対パスを生成する
- `test -f` を利用して対象ファイルの存在を確認する
- 実行方法ごとに条件分岐し、対応する実行処理を実行する
- 実行前に必ず利用者へ確認を行う
- 他スクリプトからは `bash select_file.sh` として呼び出せる構成とする
- 実行結果は終了ステータスで判定し、正常終了は `exit 0`、異常終了は `exit 1` とする
