# BASE_DIR 設計方針

## 基本方針

- `BASE_DIR` は各スクリプトの先頭で取得する。
- `settings.conf` は共通設定のみを管理する。
- `.bashrc` には依存しない設計とする。

---

## スクリプト構成

```bash
#!/bin/bash

# プロジェクトルート取得
BASE_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"

# 共通設定読込
source "${BASE_DIR}/config/settings.conf"

# メイン処理
```

---

## settings.conf

設定値のみを管理する。

```bash
# Database
DB="${BASE_DIR}/db/study.db"

# Log
LOG_DIR="${BASE_DIR}/logs"
LOG_KEEP_COUNT=30
SQL_LOG_PREFIX="sql_exec"
SHELL_LOG_PREFIX="shell_exec"
```

※ 処理（関数・コマンド）は記述しない。

---

## この設計にする理由

- `.bashrc` に依存しない。
- スクリプト単体で実行できる。
- `BASE_DIR` を最初に取得するため処理順が自然。
- `settings.conf` は設定管理だけに集中できる。
- 変更箇所を設定ファイルへ集約できる。
- 本来実装したいログ機能へ集中できる。
- 将来的なディレクトリ構成変更にも対応しやすい。
