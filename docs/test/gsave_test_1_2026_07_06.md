# gsave() テスト・修正記録

## テスト1：変更なし

### テスト内容

```bash
if git status --short | grep -q .; then
    echo "変更・新規作成あり"
else
    echo "変更なし"
    exit 0
fi
```

### 現象

「変更なし」と表示されるだけのはずが、

```
warning: Not a git repository
usage: git diff --no-index ...
```

が表示された。

### 原因

使っていない変数の中で、

```bash
git diff --name-only
```

を実行していた。

Gitリポジトリへ移動する前に実行していたためエラーになった。

### 対処

- 不要になった `git diff` を削除
- GitHubには現在使用しているコードのみを残す

### 学んだこと

- warning や fatal が表示されたら、直前に実行したコマンドを確認する。
- `usage:` はコマンドの使い方（書式）を表示している。
- エラー時は「書き方」や「実行場所」が間違っていないか確認する。

## テスト2：変更あり（フォルダ1つ）

### 現象

```
tr: warning: an unescaped backslash...
fatal: not a git repository
```

### 原因①

`tr` の改行指定を

```bash
tr 'n\' '_'
```

としていた。

### 対処①

```bash
tr '\n' '_'
```

へ修正。

## テスト3：変更あり（再テスト）

### 現象

```
fatal: not a git repository
```

### 原因②

`git status` を

```bash
cd "${BASE_DIR}"
```

する前に実行していた。

### 対処②

```bash
BASE_DIR=...
cd "${BASE_DIR}"

git status
```

の順番へ修正。

### 学んだこと

Gitコマンドは、

- Gitリポジトリへ移動してから実行する。

つまり、

```text
BASE_DIR取得
↓
cd "${BASE_DIR}"
↓
git status
↓
git add
↓
git commit
↓
git push
```

の順番を守る。
